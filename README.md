# Invisible on the Web: An Audit of Low-Resource Muskogean Languages in Web-Crawled Corpora

Code, annotations, and URL lists for the paper, accepted as an **oral
presentation at WaC-13** (13th Web-as-Corpus Workshop, EMNLP 2026,
Budapest).

The paper audits the presence of the six Muskogean languages (Choctaw
`cho`, Chickasaw `cic`, Muscogee `mus`, Alabama `akz`, Koasati `cku`,
Mikasuki `mik`) across seven major web corpora: the complete kept content
is 28 documents comprising 16 distinct texts; quality filters, not
language identification, decide what survives; the filters discard about
twice as many genuine Choctaw documents as they keep; and four of the six
languages have no representational path into any current corpus.

## What is (and is not) released here

Following the CARE principles and the paper's Ethics Statement, this
repository releases **document-level annotations, URLs, and derived
statistics only — never scraped text**. Files containing document text
(corpus downloads, seed-page fetches, annotation working files with text
columns) are excluded by `.gitignore` and have never been tracked.

**Correction and removal.** If you are a member or representative of one
of the nations whose languages are discussed here, or a steward of a site
referenced in the URL lists, and you would like anything corrected or
removed, please open an issue in this repository; such requests will be
honored.

## Layout

- `src/` — all pipeline scripts (corpus presence census, kept-document
  audit statistics, removed-pile re-identification and analysis, seed-set
  construction, GlotLID stress test, fastText lid.176 cross-check)
- `src/plots/` — figure and table generators (read `results/` only)
- `data/audit/` — annotation files (judgments + criteria; no text)
- `results/` — one JSON per experiment, each with config and git hash
- `figures/` — the generated figure (colorblind-safe vector PDF)
- `DATA.md` — every dataset used, with its license

## Reproducing

Python 3.11 with `fasttext`, `pandas`, `datasets`. GlotLID v3
(`cis-lmu/glotlid`, Apache 2.0) and fastText `lid.176.ftz` are public
models. Corpus subsets download from Hugging Face
(`HuggingFaceFW/fineweb-2`, `cis-lmu/GlotCC-V1`);
`src/download_corpora.py` fetches them. Every number in the paper is
generated by a script in `src/` writing to `results/`; figures and tables
are generated only by `src/plots/`.

> Note: the `git_hash` values recorded inside `results/*.json` files
> refer to commits of the private development repository; all results are
> regenerable from the scripts in `src/`.

## Integrity rules used throughout

- No fabricated or hand-typed numbers; every reported number traces to a
  results file with the producing script and git hash.
- Real, verified citations only.
- Manual audit annotations recorded per-document with criteria stated
  (`data/audit/annotations_kept.json` carries the schema).
